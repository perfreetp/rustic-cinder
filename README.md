# 攀岩路线三维规划器

面向室内攀岩馆定线员的三维路线规划工具。加载岩壁网格与岩点实例集合后进入编辑视口，
完成点选/框选定线、自动平滑弧线、难度色带评定、路线库管理与双路线对比。

## 技术栈

- **Vue 3 + TypeScript + Vite + Pinia**
- **three.js**（WebGL 三维渲染、InstancedMesh 实例化、Catmull-Rom 样条）
- **three-mesh-bvh**（射线拾取加速）

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npm run typecheck  # 仅类型检查
```

启动后自动加载内置演示数据：**20,000 三角面的造型岩壁 + 1,200 个岩点实例**。

## 功能与实现

### 编辑视口交互
- **悬停高亮**：鼠标悬停岩点显示脉冲线框壳、编号与朝向法线（ArrowHelper）。
- **点击拾取**：单击岩点加入当前路线；再次单击移出。`Shift+点击` 追加选择。
- **框选批量选中**：在空白处按住左键拖出矩形，屏幕空间反投影批量选中并加入路线，
  自动应用当前颜色筛选。
- **按颜色筛选**：点亮一个或多个岩点颜色后，仅这些颜色可被悬停/拾取/框选，其余压暗。
- **拖拽重算**：拖动路线中的中间岩点，投影到岩壁 BVH 表面移动，整条平滑弧的切线实时重算。

### 拾取性能（three-mesh-bvh）
- 岩壁几何构建几何级 `MeshBVH`，用于拖拽时的墙面射线投影（`firstHitOnly`）。
- 1,200 个岩点以 `InstancedMesh` 渲染，并构建**对象级 `ObjectBVH`**——每个实例是一个
  叶节点，射线检测直接返回 `instanceId`，无需遍历全部实例。实测单次拾取均值约 0.03ms。
- 悬停检测经 `requestAnimationFrame` 合并，避免鼠标移动事件风暴。

### 路线弧线
- 锚点沿各岩点法线向外侧（攀爬者一侧）偏移。
- `CatmullRomCurve3`（centripetal，防过冲）平滑后重采样生成管状几何。
- 管壁标架以岩点法线为参考，避免 Frenet 标架翻转。
- 顶点色按每段难度色带插值。

### 端点标记（三种样式）
- 起步点：绿色圆锥；奖励点：金色八面体；顶点：紫色五角星。
- 标记模式下点击路线内岩点分配，同类端点全局唯一；起点默认由首个岩点承担。

### 难度色带（V0–V8）
- 依据岩点序列的**相邻间距均值**与**行进方向折角均值**，分别映射到 0–8 档后综合定级。
- 9 档间距阈值与 9 档转角阈值均可通过滑块调整，调整后整条弧线立即重新着色。
- 色带配色由冷（V0 绿）到暖（V8 深红）。

### 透明排序（不闪烁）
- 岩壁半透明且 `depthWrite: true`、`renderOrder = 0`，先写入深度；
- 弧线/选中环/标记/标签 `depthWrite: false` 且 renderOrder 递增，在岩壁之后绘制；
- 岩壁启用 `polygonOffset` 避免与岩点共面闪烁。

### 路线库与分享
- 多条路线以 `localStorage` 持久化。
- 单条路线可导出为 JSON 文件（含有序岩点编号、端点、阈值、难度、岩壁指纹）。
- 导入时**按岩点编号回填**，自动剔除当前岩壁不存在的编号并提示岩壁指纹不一致，随后重建弧线。

### 对比视图
- 并排两个独立 WebGL 视口显示两条路线，支持相机姿态联动。
- 统计共用岩点、仅 A 有、仅 B 有的编号集合差异。

## 目录结构

```
src/
├── types.ts                 共享类型
├── App.vue                  应用骨架
├── stores/routeStore.ts     Pinia：路线/选择/筛选/阈值/路线库/导入
├── lib/
│   ├── grade.ts             V0–V8 难度算法与配色
│   ├── routeCurve.ts        法线偏移 + Catmull-Rom 平滑弧 + 顶点色带
│   └── storage.ts           localStorage、导入导出 JSON
├── three/
│   ├── demoData.ts          2 万面岩壁 + 1200 岩点演示数据
│   ├── EditorScene.ts       编辑视口：BVH 拾取/框选/拖拽/弧线/标记/排序
│   └── RouteViewer.ts       对比视图只读场景
└── components/              视口、筛选、序列、标记、色带、路线库、对比组件
smoke-test/cdp-smoke.mjs     无头 Chrome CDP 运行时冒烟测试（18 项）
```

## 运行时测试

`smoke-test/cdp-smoke.mjs` 通过 CDP 驱动本机无头 Chrome，覆盖渲染、拾取、框选、
筛选、端点标记、持久化、导入往返、阈值调整、对比视图、拾取性能与拖拽重算共 18 项断言。
需先 `npm run dev`，再：

```bash
node smoke-test/cdp-smoke.mjs
```
