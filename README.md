# 住宅室内采光时段模拟

基于 TypeScript + SolidJS + three.js(potree-core)的住宅室内采光模拟工具。
选择城市和日期后,系统按太阳轨迹计算全天太阳方位角/高度角,拖动时间滑块(06:00–18:00)
即可看到阳光穿过窗户在室内形成的光斑移动、墙体与家具阴影实时更新,并可在任意时刻
框选室内区域记录光照强度,自动判定采光不足区域。

## 功能模块

1. **房间加载** — 设置面宽/进深/层高;支持加载 potree 格式点云(`cloud.js` 地址),未加载时使用程序化房间(含床、衣柜、书桌、沙发)。
2. **窗户布置** — 在任意墙面添加窗户,调整朝向(所在墙)、沿墙偏移、窗宽/窗高、窗台高度、横竖窗梃数量、边框宽度与边缘柔和度。
3. **时段模拟** — 选择城市(内置 15 个中国城市经纬度)与日期,时间滑块 06:00–18:00 连续拖动或自动播放;实时显示太阳方位角与高度角。
4. **采光标记** — 框选地面区域,按工作面(0.75m)采样计算平均照度(lux),低于阈值(默认 300 lx,可调)标红为「采光不足」;支持导出/导入采光记录 JSON 文件。

## 联动重算

拖动时间滑块时四处联动:太阳方位(平行光方向)→ 阴影贴图 → 光斑投射 → 采光标记照度,
全部实时重算。窗户/房间参数修改同样触发全链路更新。

## 技术要点

- **太阳轨迹**:NOAA 近似算法(均时差 + 赤纬 + 时角),直射法线照度与天空漫射照度经验模型。
- **光斑投射**:窗口网格化采样,逐格向室内做光线投射(与地板/墙面/家具求交)生成光斑网格;
  片元着色器按窗框结构(边框 + 横竖梃)计算 SDF,`smoothstep` 实现随窗框变化的柔和边缘。
- **阴影**:平行光 PCFSoft 阴影贴图,天花板不可见但参与投影。
- **照度采样**:标记区域 8×8 采样点,射线穿窗检测 + 家具遮挡,直射 + 漫射模型。
- **剖视**:墙体为朝室内单面,室外观察时近墙自动剔除(娃娃屋效果)。
- **持久化**:房间/窗户/标记/阈值存于 `localStorage`,可导出采光记录文件分享。

## 运行

```bash
npm install
npm run dev      # http://localhost:5273
npm run build    # 产物在 dist/
```

## 测试

```bash
node scripts/smoke.mjs     # 需本机装有 Edge,验证渲染/联动/标记/持久化
node scripts/topview.mjs   # 俯视图截图,验证光斑随时间移动
```
