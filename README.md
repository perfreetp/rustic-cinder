# 竹编灯罩编织预览工具

基于 **TypeScript + React 18 + three.js + Vite** 的竹编灯罩设计与实时编织预览工具。
导入或手绘灯罩母线 → 生成回转曲面 → 在曲面上自动生成内外两层交织的平纹编织路径，
篾条截面沿曲面法向贴合，并支持侧光/背光预览与配置文件导出载入。

## 功能模块

| 模块 | 能力 |
| --- | --- |
| **母线编辑** | r–z 平面拖拽控制点、双击增删点、手绘描边自动抽稀、CSV/JSON 导入、控制点数值表格 |
| **编织参数** | 篾宽 2–8 mm、篾厚 1–3 mm、每族根数（最多 1000，共 2000 根）、螺旋角、覆盖间隙系数、固定/自动圈数、交叉安全间隙、渲染 LOD |
| **光照预览** | 侧光（外部方向光看油亮高光/浮雕）与背光（内部点光源看背面透光/缝隙光）一键切换；清漆度、不透明度、基色调节；参考曲面/母线开关 |
| **导出** | 配置 JSON（母线控制点 + 全部参数，可再次载入复现）、母线 CSV、当前编织几何二进制 STL |

## 核心几何原理

- **母线**：centripetal Catmull-Rom（α=0.5）样条，抑制过冲自交，按弧长等距重采样。
- **回转曲面**：母线绕 Y 轴旋转，提供任意 `(s, θ)` 处的位置、外法向、母线切向、周向切向活动标架。
- **螺旋路径**：统一参数化 `θ(s) = ±K·∫ds/r(s) + 2πk/N`，`r·dθ/ds = ±K`，在锥面上仍为测地螺旋；
  `K` 由螺旋角（自动模式）或固定圈数反解，螺旋角/间隙系数/圈数都真实驱动几何。
- **平纹浮沉**：两族篾条按菱形棋盘格奇偶性一上一下，中心线沿曲面法向余弦起伏，
  交叉点两中心线法向间距恰为 `厚度 + 安全间隙`，从代数上保证**零穿插**。
- **法向贴合**：矩形截面厚度沿曲面法向 `N`、宽度沿 `N×T`，四面独立面法线，棱角清晰。
- **内外分层**：每族合并为单一 BufferGeometry，按「外层顶面+侧面 / 内层底面」两套索引拆成两个网格，
  全场景仅 **4 个网格**，draw call 与篾条数无关。

## 性能设计（2000 根流畅）

1. 几何计算（样条/积分/浮沉/缓冲）全部在 **Web Worker** 中进行，结果以 Transferable ArrayBuffer 零拷贝回传，主线程不卡顿；Worker 不可用时自动回退主线程。
2. 每族**合并几何体**，固定 4 个 draw call；155 万顶点由 GPU 单次绘制。
3. 母线拖拽/滑块联动时自动降到 45% LOD（60ms 防抖），松手后全量重建；请求序号递增，过期响应直接丢弃。
4. 实测 2000 根（1000/族、96 段/根）Worker 构建约 0.16–0.27 s。

## 透明叠加与遮挡

渲染顺序固定为「两族内层（renderOrder 10/11，关闭深度写入）→ 两族外层（20/21，开启深度写入）」。
外层承担正确遮挡，内层先绘制并参与半透明混合，背光下可清晰看到背面篾纹的叠加层次。

## 开发

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npm run typecheck  # 仅类型检查
npm test           # 引擎几何测试 + 配置往返测试
```

- `npm run test:engine`：零穿插、法向贴合包络、2000 根性能、母线联动确定性、边界规格。
- `npm run test:config`：配置导出/载入往返与损坏数据容错。
- 浏览器端到端冒烟（puppeteer-core 驱动系统 Chrome，需先 `npm run dev`）：
  `node --experimental-strip-types scripts/smoke.ts`

## 目录结构

```
src/
  core/            纯计算层（不依赖 three，可在 Worker 运行）
    spline.ts      Catmull-Rom 样条与弧长重采样
    surface.ts     回转曲面活动标架
    weave.ts       平纹编织几何引擎（螺旋/浮沉/矩形截面/缓冲）
    weaveWorker.ts Worker 入口
    store.ts       React store + Worker 调度（防抖/LOD/请求序号）
    types.ts       共享类型与通信协议
    defaults.ts    默认配置与参数范围
  three/
    SceneManager.ts 渲染器/轨道控制/双光照/材质/渲染顺序
    geometry.ts      Worker 缓冲 → 内外层网格
  components/      四个模块页 + 常驻 3D 视口 + 控件
scripts/           浏览器冒烟与配置往返测试
```

所有长度单位为毫米（mm），角度为度（°）。
