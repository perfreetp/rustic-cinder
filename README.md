# 折痕折叠动画编辑器

基于 **Vue 3 + Three.js + postprocessing** 的折纸折痕动画编辑器。在纸面上标注折痕并指定峰/谷类型，系统按折痕层级自动建树，在时间轴上为折痕角度打关键帧，父折痕角度变化时整棵子树的折面姿态沿折痕树联动重算，支持折展播放、纸面布光与 PNG 序列帧导出。

## 功能

- **折痕标注与峰谷类型**：内置 2D 标注画布，拖拽绘制谷折（蓝）/峰折（红），可切换类型、撤销、清空；内置十字双折、扇形八折、风车六角、三浦 62 折痕四个示例。
- **折痕树姿态求解**：全局平面图（节点吸附 + 孪生半边面环提取）构建折面邻接，BFS 生成折痕树；每个树边生成铰链（轴、铰链点、峰谷符号、侧向符号）。含环图案（辐射共点）中的冗余折痕会被单独标注。
- **折痕角度关键帧**：每条折痕独立轨道，线性插值采样，帧范围 0–120（硬上限），时间轴可拖动播放头、增删改关键帧。
- **子树联动**：改任意父折痕角度，其下所有子折面沿树级联重算（Rodrigues 铰链变换，列主序 mat4）。
- **Worker 并行**：折痕树按面分块派发到 Worker 池（`navigator.hardwareConcurrency`，2–6 个），子树 BFS + 顶点变换在 Worker 内完成，紧凑分区缓冲 transfer 回主线程；小模型/Worker 不可用时自动回退同步求解。
- **两级渲染调度**：交互/播放时先同步更新低精度粗网格保证手感，高精度细分网格经帧合并后由 Worker 补全；过期结果按 token 丢弃。
- **纸面着色**：自定义 ShaderMaterial —— 程序化纤维纹理（各向异性噪声）+ 多方向漫反射 + 轮廓光（rim light），折面朝向光源时漫反射强度随法线夹角变化。
- **三组布光**：右上主光 / 左侧逆光 / 低角度侧光一键切换。
- **接触阴影**：正交相机渲染深度图，纸面着色器 5 抽头 PCF 采样软阴影。
- **后处理**：postprocessing 的 SSAO、Outline（选中折痕高亮）、Bloom、Vignette。
- **导出**：逐帧高精度求解后截屏，打包 PNG 序列帧 + `keyframes.json` + `manifest.json` 为 ZIP；也可单独导出关键帧 JSON。

## 快速开始

```bash
npm install
npm run dev      # 开发服务器
npm test         # 核心数学/求解 + Worker 并行一致性测试
npm run build    # 生产构建
```

```
  core/

    model.js         平面图构建：节点吸附 → 孪生半边面环 → BFS 折痕树 → 铰链
    meshBuilder.js   低/高精度两套三角网格 + 逐面顶点区间 + 折痕边

    solverPool.js    主线程 Worker 池封装与同步回退、过期请求作废
    keyframes.js     关键帧存储、线性采样、序列化（120 帧上限）
    presets.js       四个示例折痕图
    exporter.js      PNG 序列帧 + 关键帧 ZIP 导出
  workers/
    poseWorker.js    折痕树重算 Worker（子树 BFS + 紧凑分区顶点变换）
  render/
    viewport.js      3D 视口、双精度网格、折痕线、后处理、轨道相机
    paperShader.js   纤维/漫反射/轮廓光纸面着色器与三组布光
    contactShadow.js 正交深度图接触阴影
  store/
    editorStore.js   Vue 响应式状态、两级求解调度、播放控制
  components/        Vue 组件（顶栏/左栏标注/视口/右栏属性/时间轴）
```

## 关键设计

### 折痕树与铰链

每条用户折痕在交叉处拆为子段（共享 `parentId`，关键帧仍按用户折痕分组）。BFS 生成树的每个非根面得到一条铰链：

```
旋转角 θ = sideSign × typeSign × radians(折痕角度)
变换    = T(p) · R(axis, θ) · T(−p)
子面矩阵 = 父面矩阵 × 局部铰链变换
```

`sideSign` 区分子面在折痕哪一侧，`typeSign` 区分峰（−1）谷（+1），因此同一角度驱动对峰谷折痕产生相反折叠方向。

### 60+ 折痕性能

三浦示例 62 折痕 / 63 折面 / 约 1.1 万高模顶点，单帧全量求解 + 顶点变换约 1ms（Node 基准），Worker 4 路并行有充分余量。Worker 只回传所属面的紧凑顶点分区（offset + data），主线程按偏移回填，避免全尺寸缓冲的零值互相覆盖。

### 冗余折痕

辐射共点等含环图案的折痕数多于生成树边数，未被选为树边的折痕是运动学冗余约束（其折叠由相邻折痕决定），在 UI 中标注为「冗余」，不计入独立铰链但仍保留峰谷类型与关键帧轨道。
