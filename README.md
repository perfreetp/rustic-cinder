# 辉光溢出合成器 · Glow Bloom Lab

游戏特效里「自发光物体光晕」的调试工具。TypeScript + SolidJS + three.js（WebGL2 / HDR）。

核心是多级降采样辉光与**遮挡联动**：自发光物体被其它几何体挡住时，
其辉光按屏幕上的可见比例衰减；环绕相机时遮挡关系持续变化，光晕实时反映。

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览生产构建 http://127.0.0.1:4173
npm test           # 单元测试（41 项）
npm run test:e2e   # 真实浏览器端到端验证（需先 npm run preview）
```

需要支持 WebGL2 的浏览器（Chrome / Edge / Firefox / Safari 15+）。

## 四个模块

### 1. 场景载入 — `src/scene/scene.ts`

- 6 个自发光物体（HDR 线性颜色，峰值 > 1），分布在中央石柱与外圈立柱之间
- 每个物体可单独开关（侧栏「场景」区的物体行）
- 轨道相机：拖拽环绕、滚轮缩放，可选自动环绕
- 遮挡几何体：中央石柱、8 根立柱、两块悬空板、地面

### 2. 亮度提取 — `src/core/brightness.ts` + `EXTRACT_FRAG`

- 阈值范围 **0 ~ 2**，只保留亮度高于阈值的像素作为辉光源
- 另有**软阈值过渡宽度**（knee 0~2）：阈值到阈值+宽度之间用 smoothstep 过渡，
  0 时为标准硬阈值
- 提取的同时做 2×2 盒式降采样，并乘以该像素所属物体的遮挡增益

### 3. 辉光分级 — `src/core/pipelinePlan.ts` + `src/render/pipeline.ts`

五级降采样缓冲，L0 = 1/2 分辨率 … L4 = 1/32：

| 级别 | 分辨率 | 独立半径 | 独立权重 |
|------|--------|----------|----------|
| L0 | 1/2  | ✓ | ✓ |
| L1 | 1/4  | ✓ | ✓ |
| L2 | 1/8  | ✓ | ✓ |
| L3 | 1/16 | ✓ | ✓ |
| L4 | 1/32 | ✓ | ✓ |

合成时**由细到粗**逐级叠加：`acc[i] = acc[i-1] + upsample(blur[i]) × weight[i]`。

**增量重算**：每级半径只影响自身与更粗的层，因此拖动 L<i> 的半径时，
只重算 `blur[i]` 与 `acc[i..4]`，更细的 `acc[0..i-1]` 直接复用。
纯相机不动、参数不变时整条链零 pass。

### 4. 导出 — `src/export/exporter.ts` + `src/core/params.ts`

- **PNG**：当前绘制缓冲分辨率（与屏幕显示一致，sRGB 编码）
- **JSON**：阈值、软阈值宽度、五级半径与权重、曝光/强度、遮挡配置，
  以及导出瞬间每个物体的可见比例与增益

## 遮挡联动

`src/core/occlusion.ts`：

1. 在每个自发光物体的包围球投影范围内做 Vogel 螺旋低差异采样（16 条射线）
2. 每条射线从球面朝相机一侧的表面点出发，向相机方向打一条短射线
3. 若被其它几何体拦住，该采样点记为被遮挡
4. 可见比例 = 未被遮挡的采样数 / 总数，帧率无关的指数平滑后写入物体增益
5. 增益在亮度提取阶段乘到该物体的辉光上

射线查询通过 `three-mesh-bvh` 加速。相机移动后可见比例会重算，
增益变化超过 2% 时把辉光源标脏，触发链路重算 —— 所以**被挡住时不会残留满额辉光**。

侧栏每个物体右侧的进度条即其实时可见比例；「遮挡掩码」视图用物体 ID 着色、
亮度表示可见比例，可直观检查遮挡关系。

## 性能

五级缓冲在 1080p 下参数拖动保持流畅（SwiftShader 软件光栅化下实测）：
拖动滑块中位 **0.20 ms** / p95 **0.30 ms**（`gl.finish()` 同步测量，含执行时间）。

- 渲染目标只在尺寸变化时分配一次，降采样链不重复分配纹理
- 无变化时跳过场景重绘和整条辉光链

## 视图模式

| 模式 | 内容 |
|------|------|
| 合成 | 场景 + 辉光，ACES 色调映射 |
| 仅辉光 | 只看五级辉光叠加结果 |
| 亮度源 | 阈值提取后的辉光源（已乘遮挡增益） |
| 遮挡掩码 | 物体 ID 着色 × 可见比例 |

## 目录结构

```
src/
  core/       画面无关的纯逻辑（阈值数学、分级调度、遮挡采样、参数与导出结构）
  scene/      three.js 场景、相机、遮挡几何体
  render/     着色器、辉光管线、查看器循环
  export/     PNG + JSON 导出
  ui/         SolidJS 组件
tests/        单元测试
scripts/      e2e.mjs（浏览器端到端验证）
```

## 测试

- `npm test`：41 项单元测试，覆盖亮度阈值语义、分级脏标记调度、遮挡可见比例与平滑
- `npm run test:e2e`：headless Chrome 打开真实页面，验证渲染像素、
  遮挡联动数值、增量重算的 pass 集合、纹理不增长、PNG/JSON 导出内容、1080p 性能
