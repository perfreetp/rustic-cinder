# DNA 双螺旋装配工具

基于 **TypeScript + SolidJS + Babylon.js(WebGPU 优先,WebGL2 回退)** 的核酸双螺旋装配与可视化工具。

## 功能

- **序列输入页**:校验碱基字符(仅 A/T/G/C),实时显示序列长度与 GC 含量,支持随机序列与 240bp 长链示例。
- **螺旋装配页**:按序列生成双螺旋,碱基类型决定嘌呤/嘧啶尺寸与配色(A 绿 / T 红 / G 琥珀 / C 蓝),自动按互补规则(A-T、G-C)生成配对链。螺距(3.0–3.6 nm)与每圈碱基数可调,修改任一参数时整条链的骨架与碱基对位置联动重算。支持拖拽旋转、滚轮缩放、自动旋转;碱基与磷酸骨架使用薄实例渲染,200+ 碱基仍保持流畅。
- **配对查看页**:滑块选择任意碱基对并高亮(其余变暗),显示氢键连线(A-T 两条、G-C 三条),可切换磷酸骨架与碱基平面的显示。
- **导出页**:一键导出 GLB 文件;轴向剖面视图(俯视 + 裁剪平面)查看任意高度的碱基堆叠;显示当前碱基对总数;多序列本地库管理(切换 / 删除),序列与参数自动保存在浏览器 localStorage。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 类型检查 + 生产构建
npm run preview  # 预览生产构建
```

## 结构

```
src/
  dna.ts                 # 序列校验、GC 含量、双螺旋几何布局计算(纯函数)
  store.ts               # Solid store:多序列 + 参数,localStorage 持久化
  scene/helixScene.ts    # Babylon 场景:WebGPU/WebGL 引擎、薄实例渲染、氢键连线、轴向剖面
  scene/useHelixScene.ts # Solid 组件挂载场景的 Hook
  pages/                 # 序列输入 / 螺旋装配 / 配对查看 / 导出 四个模块
```

## 几何模型

- 螺旋轴为 Y 轴,骨架半径 1.0 nm,每个碱基上升 `螺距 / 每圈碱基数` nm。
- 嘌呤(A/G)碱基更长更宽,嘧啶(T/C)较短,互补碱基从对侧骨架伸向轴心。
- 氢键连线位于两碱基内端点之间。
